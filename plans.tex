\subsubsection{3. inspecting objects:}
\label{sec:org79e1aca}

Inspecting: start with two functions: type() and dir()

Using type() and dir() to better understand our response data. The end
goal is to sift through the data to discover interesting things.

\begin{verbatim}

# what type of object do we have?

type(women)

# What can we do with a Response object? Spend a couple of minutes exploring the different methods.
dir(women)

\end{verbatim}

Then, use .json() to parse our response object, and .keys() to see the
keys (labels). 

\begin{verbatim}

# why do we need to add parenthesis? 
  parsed = women.json()

  # what is it
  type(parsed)

  # we can use .keys() to get the keys

  parsed.keys()

\end{verbatim}

\subsection{collecting several objects}
\label{sec:org4ee6bac}
What if we want to collect data on several objects, and save them to a
spreadsheet, with columns like "artist", "title", etc.?
\begin{itemize}
\item write a loop that makes calls to each objectID, parses the response,
and adds to a list. (Will end with a list of dicts)
\end{itemize}

Write it out in pseudocode
\begin{itemize}
\item make a list of objectIDs
\item write a loop
\item make call to objectID
\item parse response
\item append response to list
\end{itemize}

\begin{verbatim}
from time import sleep

# just the first ten
ids = parsed['objectIDs'][:10]

# start small, just print the ids for now
for item in ids:
  print(item)

# add pseudocode, then fill it in
# what are the steps we need to take?

first_ten = []
for item in ids:

    # passing the objectID variable into the URL
    base_url = 'https://collectionapi.metmuseum.org'
    path = '/public/collection/v1/objects/'
    url = f'{base_url}{path}{item}'

    # grabbing our response for that object
    response = requests.get(url)

    # parsing our response with json
    parsed = response.json()

    sleep(1)

    # appending the response to our new list
    first_ten.append(parsed)

# check the content.
type(first_ten)

\end{verbatim}

Now, we have a list object with tons of information that we can
extract from.

How can we extract this information? Let's say, the artist name?

\begin{verbatim}
for item in first_ten:
  print(item['artistDisplayName'])
\end{verbatim}

This gives us an error
